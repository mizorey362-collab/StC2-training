# Replay Review Checklist

> Use this for every replay you watch. ~15 minutes per game. Log patterns to [[Common Mistakes]].

---

## Before You Watch

- [ ] Note your assumption of why you won/lost:
  > *"I think I lost because ___"*
- [ ] Open [[Common Mistakes]] to log findings as you go

---

## Economy Check (Pause @ 6:00)

- [ ] Did I hit **66 drones by 6:00**? → [[Zerg Macro Benchmarks]]
- [ ] Was I floating minerals? (>400 unspent = income wasted)
- [ ] Supply blocks? Count: ___
- [ ] Idle larvae at any hatch?

---

## Inject Review (Pause @ 8:00)

- [ ] Were queens ever idle (orange energy bar visible)?
- [ ] Inject gaps > 30 seconds?
- [ ] Were all 3 hatcheries consistently injected?
- [ ] Queens lost before 8 min?

Rating: ___/5 → log in game file `injectrating`
See [[Inject Practice]] if rating was 3 or below.

---

## Scouting Check

- [ ] Scouted by 2:00 (overlord)?
- [ ] Second scout at 4:00–4:30?
- [ ] Identified opponent build before attack arrived? → [[Build Recognition System]]
- [ ] Reacted correctly to what was scouted? → [[Zerg Decision Tree (First 8 Minutes)]]

Scouting score: ___/5 → log in game file `scouting_score`

---

## Creep Spread (Pause @ 8:00)

- [ ] First tumor placed by 3:30?
- [ ] Creep past natural by 6:00?
- [ ] Natural queen walking toward 3rd base?
- [ ] Fighting on creep (or off creep)?

Rating: ___/5 → log in game file `creeprating`
See [[Creep Spread Practice]] if rating was 2 or below.

---

## Production Check

- [ ] Correct units for the matchup?
- [ ] Army size appropriate for threat level?
- [ ] Drone production resumed after defending?
